# OrderMate Pro

Create Web App สำหรับร้านอาหาร เพื่อให้พนักงานรับออเดอร์ ระบุเลขโต๊ะ เมนูที่สั่ง และการคอนเฟริ์มออร์เดอร์ได้อย่างรวดเร็ว ใช้งานง่าย รองรับทั้งแท็บเล็ตและคอมพิวเตอร์



ผู้ใช้งานสามารถระบุเลขโต๊ะ เลือกเมนูจากหมวดหมู่หรือค้นหา เพิ่มรายการอาหารลงในออเดอร์ ปรับจำนวน เห็นรายการที่กดสั่ง และตรวจสอบรายการ คำนวณยอดรวม และดำเนินการคอนเฟริ์มออร์เดอร์เข้าระบบ



หน้าจอแรกแบ่งเป็น 2 ส่วน โดยด้านซ้ายเป็นรายการเมนูพร้อมหมวดหมู่และช่องค้นหา และระบุเลขโต๊ะ ส่วนด้านขวาเป็น Order Summary ที่แสดงรายการอาหาร ยอดรวม และปุ่ม สรุปออร์เดอร์ ซึ่งมองเห็นได้ตลอดเวลา
